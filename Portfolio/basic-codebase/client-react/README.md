# Client React

A modern React and TypeScript front-end built with Vite, featuring a modular structure for routing, state management, and reusable UI components.

## Tech Stack

- React 19
- TypeScript
- Vite
- React Router DOM
- Redux Toolkit with React Redux
- TanStack React Query
- Tailwind CSS
- React Hook Form
- Zod for schema validation
- ESLint and TypeScript ESLint

## Project Structure

- src/app for app-level providers, layout, and store setup
- src/features for feature-specific modules such as authentication
- src/routes for page-level route definitions
- src/shared for shared UI components and reusable helpers

## Getting Started

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```
