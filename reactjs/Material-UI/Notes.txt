Packages Explained
@mui/material → The core Material UI component library → Buttons, TextFields, Cards, Dialogs, etc.
@emotion/react → Required styling engine for MUI (CSS-in-JS)
@emotion/styled → Enables styled components using Emotion
@mui/icons-material → Material Design icons as React components → Example: <HomeIcon />, <MenuIcon />
