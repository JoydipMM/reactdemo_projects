26. Remove Duplicates from Sorted Array

Given an integer array nums sorted in non-decreasing order, remove the duplicates in-place such that each unique element appears only once. The relative order of the elements should be kept the same.

Consider the number of unique elements in nums to be k. After removing duplicates, return the number of unique elements k.

The first k elements of nums should contain the unique numbers in sorted order. The remaining elements beyond index k - 1 can be ignored.

Example

Input: nums = [0,0,1,1,1,2,2,3,3,4]

Output: 5, nums = [0,1,2,3,4,_,_,_,_,_]

Code:

Explanation:

We are using the two-pointer technique:
x → slow pointer (tracks last unique element index)
i → fast pointer (scans the array)

let x = 0;
x starts at index 0
It represents the position of the last unique element found

for(let i = 0; i < nums.length; i++)
i scans every element in the array

if(nums[i] > nums[x])
We are checking: "Is the current number greater than the last unique number?"
Since the array is sorted, if nums[i] > nums[x], it must be a new unique number.

x = x + 1;
nums[x] = nums[i];
Move x forward and Replace the next position with the new unique value
This effectively: Keeps unique values at the beginning and Overwrites duplicates

return x + 1;
Return value: 5, without +1 it will be 4 which not match with total count
