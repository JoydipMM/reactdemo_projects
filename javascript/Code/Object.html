Const Object:

const array or object can not be modify the hole data of it. We can change data by it's index (for array) or key name (for object)

const employee = { name: "Ram", age: 35 }; document.write("Actual object name keyvalue is: "+employee.name+"<br>"); employee.name = "Rahul"; document.write("Updated object name keyvalue is: "+employee.name+"<br>"); document.write("Note: But we can not change the full data, also we can not use the same variable name with const datatype, it will show error<br>");
