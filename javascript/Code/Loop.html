Loop is divided in 3 parts

  1. initialization [ initialize a variable ]
  2. Condition [ condition has two value True or False, if False then it will out of loop or value is True then loop will continue ]
  3. Increase / Decrease [ it will base on condition's situation and after it will goes to condition ]

Type of Loop

  1. while loop
  2. do/while loop
  3. for loop
  4. for/in loop [work with object]
  5. forEach [work with array]

While Loop

var a = 0; while(a < 10){ a = a+1; document.write("'a' value increased to "+ a + "<br>"); }
