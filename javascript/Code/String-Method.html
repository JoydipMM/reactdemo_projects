MethodDescriptionExample
.lengthReturns string length"Hello".length → 5
.toUpperCase()Converts to uppercase"hi".toUpperCase() → "HI"
.toLowerCase()Converts to lowercase"HI".toLowerCase() → "hi"
.slice(start, end)Extracts part of a string"Hello".slice(0,3) → "Hel"
.replace("old", "new")Replaces part of a string"Hello".replace("l", "p") → "Heplo"
.trim()Removes spaces from both sides" hi ".trim() → "hi"
.split("separator")Splits into an array"a,b,c".split(",") → ["a", "b", "c"]
.includes("text")Checks if text exists"Hello".includes("lo") → true
.indexOf("text")Finds first occurrence"Hello".indexOf("l") → 2
.repeat(n)Repeats the string"Hi".repeat(3) → "HiHiHi"
