Array Filter

The filter() method creates a new array containing all elements that satisfy a given condition. Unlike find(), which returns only the first matching element, filter() returns all matching elements.

var age = [10, 18, 23, 8, 11]; document.write("Actual Data: "+ age+"<br>"); var filterAge = age.filter( age => age >=18 ); document.write("Filter Data: "+ filterAge+"<br>");
