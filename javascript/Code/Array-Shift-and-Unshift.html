Array Shift & Unshift

Shift Method: Always remove/delete the value of first index of an array

Unshift Method: Always add a new value at the first index inside a array

var arrayData = ["Sanjay", "Aman", "Raman", "Karan"]; document.write("Actual Array: "+arrayData+ "<br>"); arrayData.shift(); document.write("After pop method: "+arrayData+ "<br>"); // "Sanjay" removed arrayData.unshift("Rahul"); document.write("After push method: "+arrayData+ "<br>"); // "Rahul" added at the first
