Array Pop & Push

Pop Method: Always remove/delete the value of last index of an array

Push Method: Always add a new value at the last index inside a array

var arrayData = ["Sanjay", "Aman", "Raman", "Karan"]; document.write("Actual Array: "+arrayData+ "<br>"); arrayData.pop(); document.write("After pop method: "+arrayData+ "<br>"); // "Karan" removed arrayData.push("Rahul"); document.write("After push method: "+arrayData+ "<br>"); // "Rahul" added at the last
