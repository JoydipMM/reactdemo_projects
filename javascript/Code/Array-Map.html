Array Map

The .map() method is used to create a new array by applying a function with to each element of an existing array, we can also modify each element. It does not modify the original array.

var arrayData = [10, 20, 24, 56, 67]; document.write("Actual array: "+arrayData+"<br>"); var arrayMapData = arrayData.map( number => number*10); document.write("with map(): "+arrayMapData);
