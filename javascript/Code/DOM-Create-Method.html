DOM Create Method

  • createElement: [append only] The createElement() method allows you to dynamically create HTML elements in JavaScript.
  • CreateTextNode: [append only] The createTextNode() method creates a text node that can be added to an HTML element. It's useful when you want to add plain text without using innerHTML (which can be unsafe for user input).
  • createComment: [append only] The createComment() method creates a comment node that can be added to the DOM. This is useful for adding developer notes dynamically without affecting the visible content of the webpage.
  • insertAdjacentElement: [create and append] insertAdjacentElement is a JavaScript method that allows you to insert an element into the DOM at a specified position relative to another element. It is a method of the Element interface.

    targetElement.insertAdjacentElement(position, newElement);

    position (string) – Specifies where to insert the element. Acceptable values:

    • "beforebegin" – Before the target element itself.
    • "afterbegin" – Inside the target element, before its first child.
    • "beforeend" – Inside the target element, after its last child.
    • "afterend" – After the target element itself.
    • newElement (Node) – The element to insert.
