JavaScript Arithmetic Operators

Arithmetic operators perform arithmetic on numbers (literals or variables).

  • Operator: **
  • Equivalent: Math.pow(base, exponent)
  • Associativity: Right-to-left
Operator Description
+ Addition
- Subtraction
* Multiplication
** Exponentiation (ES2016)
/ Division
% Modulus (Remainder)
++ Increment
-- Decrement

Exponentiation Operator

The Exponentiation Operator in JavaScript, represented by **, is used to raise a number to a power.

Syntax

base ** exponent
  • base: The number you want to raise.
  • exponent: The power to which you want to raise the base.

Example Usage

console.log(2 ** 3); // 8 (2 raised to the power of 3)
console.log(5 ** 2); // 25 (5 squared)
console.log(10 ** -1); // 0.1 (10 raised to the power of -1)

Equivalent to Math.pow()

The exponentiation operator ** is functionally equivalent to Math.pow (base, exponent):

console.log(2 ** 3); // 8
console.log(Math.pow(2, 3)); // 8

Associativity

The exponentiation operator is right-associative, meaning it evaluates from right to left:

console.log(2 ** 3 ** 2); // 2 ** (3 ** 2) -> 2 ** 9 -> 512

Usage with Assignment Operator

You can also use the exponentiation operator with the assignment operator to shorten code:

let num = 4;
num **= 2; // Equivalent to num = num ** 2
console.log(num); // 16
