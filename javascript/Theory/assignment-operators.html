JavaScript Assignment Operators

Assignment operators assign values to JavaScript variables.

Operator Example Same As
=
The Simple Assignment Operator assigns a value to a variable.		 x = y
-----------------------------
let y = 50
let x = 10 + y;
console.log(x) // Value of x is: 60
x = y
+=
The Addition Assignment Operator adds a value to a variable. 		x += y
----------------------------------
let x = 10;
x += 5;
console.log(x) // Value of x is: 15
----------------------------------
let text = "Hello";
text += " World";
console.log(x) // Hello World
x = x + y
-=
The Subtraction Assignment Operator subtracts a value from a variable.		 x -= y
----------------------------------
let x = 10;
x -= 5;
console.log(x) // Value of x is: 5
x = x - y
*=
The Multiplication Assignment Operator multiplies a variable.		 x *= y
-----------------------------
let x = 10;
x *= 5;
console.log(x) // Value of x is: 50
x = x * y
/=
The Division Assignment Operator divides a variable.		 x /= y
-----------------------------
let x = 10;
x /= 5;
console.log(x) // Value of x is: 2
x = x / y
%=
The Remainder Assignment Operator assigns a remainder to a variable.		 x %= y
-----------------------------
let x = 10;
x %= 5;
console.log(x) // Value of x is: 0
x = x % y
**=
The Exponentiation Assignment Operator raises a variable to the power of the operand. 		x **= y
-----------------------------
let x = 10;
x **= 5;
console.log(x) // Value of x is: 100000
x = x ** y
