JavaScript Interview Questions



What is JavaScript?

JavaScript (JS) is a Single-Threaded, synchronous, high-level, dynamic, interpreted programming language primarily used to make web pages interactive and dynamic.

Examples:

  • Display dynamic content.
  • Handle button clicks.
  • Validate forms.
  • Fetch data from APIs.
  • Create animations.
  • Update webpage content without reloading.
  • Build complete web applications.
Single-Threaded

Single-Threaded means JavaScript executes one piece of synchronous JavaScript code at a time using a single call stack.

What is a Thread?

A thread is the smallest unit of execution within a process. A thread is responsible for executing instructions or tasks in a program.
Consider this example:
Explaination

1. Executes console.log("First").
2. Executes console.log("Second").
3. Executes console.log("Third").
Synchronous Programming
Synchronous programming is an execution model in which statements are executed one after another. The next statement waits until the current statement finishes executing. In simple words, JavaScript executes one task at a time on its main call stack.
However, JavaScript also supports asynchronous programming using mechanisms such as callbacks, Promises, async/await and the Event Loop.

High-level programming language

A high-level programming language is a language that is easy for humans to read, write and understand compared to low-level languages such as Assembly. It hides many hardware-level complexities, so developers can focus on writing application logic rather than managing hardware directly.

Dynamic programming language (Dynamic Typing)

JavaScript is dynamically typed, which means you don't need to explicitly declare the data type of a variable. JavaScript determines the type based on the value assigned to it at runtime. means a variable can hold different types of values during program execution without explicitly declaring its type.

Here, the same variable value holds three different data types.

  • First, it stores a number.
  • Then, it stores a string.
  • Finally, it stores a boolean.
Interpreted programming language

JavaScript code is executed by a JavaScript engine, which processes the source code and executes the instructions. Modern JavaScript engines use a combination of interpretation and Just-In-Time (JIT) compilation to optimize execution.

Popular JavaScript engines:
  • V8 — Chrome and Node.js.
  • SpiderMonkey — Firefox.
  • JavaScriptCore — Safari.

Just-In-Time (JIT) Compilation in JavaScript

JIT compilation means converting JavaScript code into machine code while the program is running, so it can execute faster.
