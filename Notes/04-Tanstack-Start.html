Server Function

Server Function is a function that run on the server side. When API need API key / secret key to fetch the data, then we can not put the those key inside the loader function, because the loader function run on the client side and we can not put any API key or raw database query inside of loader, if we do then that code shift to the client browser. So to fetch data securely, loader must call Server Function.

Server Function is a piece of code that run on the server side only.So when we call server function from client code like react button click event, then Tanstack automatically transform that call in to a proper http request behind the scene. It act as a Remote Procedure Call (RPC). It means Tanstack has tRPC style architecture build natively into the framework via Server Function.

Remote Procedure Call (RPC) it means, we can execute a function that live in different computer like inside a server as if it were a normal local function. In simple words: “Call a function → but it actually runs somewhere else (server)”. Here we don't have to write any manual fetch request, define url end points, set header or parse header responses. the framwork takes care of everything while keeping typescript types parfectly intact from the client to the server. In React Eco System we have TRPC, which is massively popular standalone library to design the same type safe RPC experience.

So we get 1. End-to-end type safety of tRPC, 2. Incredible developer experience without install any separate dependencies / library.
