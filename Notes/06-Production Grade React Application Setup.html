Create React App with Vite

Create a new project using vite vite.dev

command: npx create-vite@latest

OR, if we want create react app in existing folder then command: npx create-react-app@latest ./


Install TypeScript in React JS Environment

Step 01

command: npm install -D typescript @types/react @types/react-dom

IF we use Vite then command: npm install -D @vitejs/plugin-react-swc


Step 02 Create tsconfig.json

command: npm install typescript

then run command: npm run tsc --init

It will create a tsconfig.json file
