React.js Interview Questions



What is React.js?

React is a JavaScript library for building interactive user interfaces using reusable components. It follows a declarative programming approach, where developers describe the desired UI, and React manages the necessary DOM updates when application data changes.

It was originally developed by Facebook (now Meta) and is maintained by Meta and the React community. React allows developers to build applications using reusable, independent components.

Library vs Framework

Both libraries and frameworks provide reusable functionality, but they differ in how application execution is controlled.

Library

A library is a collection of reusable functions and tools that developers call when needed.

We control the application flow. Example: React is a UI library.

Framework

A framework provides a predefined structure and controls significant parts of the application lifecycle. It calls your code at appropriate points.

Examples:

  • Angular
  • Next.js
  • Vue.js

Virtual DOM

The Virtual DOM is an in-memory representation of the UI that React uses to determine which changes need to be applied to the actual DOM.
It represents the structure of the UI using JavaScript objects.
