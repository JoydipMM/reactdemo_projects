Redux Toolkit Setup

What is Redux?

Redux is a state management tool. It helps to store and manage data for your app in one central place so different components can use and update that data without getting messy.


Redux Store:

Redux Store is a big whole object with lot of data and it kept in central global space.


Slice:

To keep data separate, we make logical partition that call Slice. Example, if we want to store cart data on store, we will create a separate slice for cart data.
Initially cart can be empty array/object. But leter on when we add data on it, it can modify the cart slice.


Why Use Redux Toolkit

Here we have counter UI, where we have increment and decrement the counter in CounterAction component and in CounterShow component we show the counter value.
Using Redux Toolkit, we can store the counter value in the store and access it from anywhere in the application.


How Redux work:

We can not add data directly inside slice. React says the way:


Update slice Flow:

When we hit the add button, it dispatches a action which calls the reducer function, which updates the slice of Redux Store.


Read data from Store:

For read data , we use something known as a “Selector” to read the data from our store and the selector will modify our react component.
Selector give us the data over here. When we use “Selector”, so this phenomena is known as subscribing to the Store.

extraReducers and createAsyncThunk

extraReducers is a property in Redux Toolkit used to handle actions that are created outside the current slice.

  • async thunk actions
  • actions from other slices
  • global actions
  • external dispatched actions

createAsyncThunk is a Redux Toolkit function used to handle asynchronous operations like:

  • API calls
  • fetching data
  • posting data
  • async business logic

It automatically generates three action types:

  • pending
  • fulfilled
  • rejected
