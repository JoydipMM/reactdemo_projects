Craete a Server

We create index.js file inside src folder


Run this command: npm run dev

If all things are fine then we will see this message Server running on port 5001 in terminal


Connect to PostgresSQL Database

To connect to database we need to create db.js file inside src/config folder. Here we write code for connecting to database


After creating db.js file we need to import it in index.js to check if we are able to connect to database


Run this command: npm run dev

If all things are fine then we will see this message The database name is postgres-db in terminal


Create Router for API where we can able to create, read, update and delete data

To create router first we need to create Models where we write code for postgres queries for CRUD. As a example we are creating CRUD API for User. For that we need to create userModel.js file inside src/models folder


What is Controller
In a production-grade Express.js app, a controller handles the business logic of your application. It receives the request from routes, processes data, talks to models/database, and sends the response.

Our model is ready. Now we create controller for user where we control all API Endpoints and call our model functions.
