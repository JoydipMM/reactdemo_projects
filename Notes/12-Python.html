Syntax and Semantics in Python

Syntax refers to the set of rules that defines the combinations of symbols that are considered to be correctly structured programs in a language. In simpler terms, Syntax is about the correct arrangement of words and symbols in a code

Semantics refers to the meaning or the interpretation of the symbols, characters and commands in a language. It is about what the code is supposed to do when it runs.


PEP 8 in Python

PEP 8 is Python's official style guide. It provides conventions for writing Python code that is readable, consistent, and easier for teams to maintain.

Important PEP 8 rules:
  1. Indentation : Use 4 spaces for indentation. Avoid mixing tabs and spaces.
  2. Variable and function names : Use snake_case.
  3. Classes : Use PascalCase.
  4. Constants : Use UPPER_CASE.
  5. Spaces around operators : Use a single space around operators.
  6. Function arguments : Use spaces after commas.
  7. Imports : Put imports at the top of the file.
  8. Line length : Traditionally, PEP 8 recommends keeping lines around 79 characters for code. The format will be like below

    Modern Python projects often use automated formatters such as Black or Ruff, so we don't need to manually count characters.

  9. Blank lines : Use blank lines to separate logical sections.
  10. Boolean comparisons
  11. Don't use unnecessary semicolons
  12. Comments

What is Object in Python

In Python, an object is a value/data that exists in memory and has a type, identity, and value.

The most populer definition of an object is Everything in Python is an object. That includes numbers, strings, lists, functions, classes, and even classes themselves.

In Python, each object has a type, identity, and value. also object can be mutable or immutable


Mutable & Immutable

In Python, mutable and immutable describe whether an object's value can be changed after the object is created.

Immutable

An immutable object cannot be changed after creation.

Common immutable types:

  • int
  • float
  • bool
  • str
  • tuple
  • frozenset
  • bytes

Example of Immutable:

suger_amount is a variable that references an integer object. Initially, it references the integer object 10. When we execute suger_amount = 20, Python does not modify the existing integer object 10. Instead, suger_amount is reassigned to reference the integer object 20. Since an integer object cannot be modified after it is created, so integers are immutable in Python. The important concept is not that 10 and 20 have different memory locations. The important concept is that the integer objects themselves cannot be changed; the variable can only be reassigned to another object.

Mutable

A mutable object can be changed after creation without creating a new object.
