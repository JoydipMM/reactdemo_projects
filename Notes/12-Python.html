Create Virtual Environment with Python
Create and Activate Virtual Environment

open terminal: python -m venv envname

activate environment: source envname/Scripts/activate

if environment activate successfully then we will see this message (envname) C:\Users\user\Documents\Python\envname in terminal

Deactivate environment: deactivate


Create Virtual Environment with Virtualenv

open terminal: pip install virtualenv, this will install virtual environment

create virtual environment: virtualenv -p python3 virtual_env "virtual_env" this one is the name of virtual environment

activate virtual environment: source virtual_env/bin/activate


Create Virtual Environment with Conda

01. install conda exe in system

02. after install open Anaconda prompt terminal and run conda --version. if it show version then it is installed successfully

03. save anaconda path to System Environment Variables > users variables for joydi > Path > add > C:\Users\joydi\miniconda3

04. To conda setup for VSCode. First open CMD and run C:\Users\joydi\miniconda3\Scripts\conda.exe init bash, some message will show in CMD, Then close VSCode and opend again. Open VSCode Terminal run this command conda --version, if it show version then it is installed successfully

05. for create environment required Conda versions require you to accept the Anaconda Terms of Service before using the default repositories. For that we run below commands:

06. create environment: conda create -p venv1 python==3.12 -y, this will create environment

07. activate environment: conda activate ./venv1

08. deactivate environment: conda deactivate

With conda we can install other python version for specific project folder by using conda create -p venv1 python==3.10 -y


Installation packages in Python

pip install flask after install we will see this message Successfully installed flask-2.2.2 in terminal

Then run flask --version in terminal we will see this message Flask 2.2.2. it is installed successfully

Now run pip freeze > requirements.txt in terminal. This will create requirements.txt file. Inside this file we can see all installed packages. So when we install any package we run pip freeze > requirements.txt for update installed packages list

Syntax and Semantics in Python

Syntax refers to the set of rules that defines the combinations of symbols that are considered to be correctly structured programs in a language. In simpler terms, Syntax is about the correct arrangement of words and symbols in a code

Semantics refers to the meaning or the interpretation of the symbols, characters and commands in a language. It is about what the code is supposed to do when it runs.
