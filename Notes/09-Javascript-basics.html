Different between var, let and const

var : was the original way to declare variables before ES6.

Characteristics

  • Function-scoped (not block-scoped)
  • Can be redeclared and reassigned
  • Gets hoisted and initialized with undefined

let : Introduced in ES6. It is block-scoped.

Characteristics

  • Block-scoped
  • Can be reassigned
  • Cannot be redeclared in the same scope
  • Hoisted but placed in the Temporal Dead Zone (TDZ). The variable exists but cannot be accessed before declaration.

const : was the original way to declare variables before ES6.

Characteristics

  • Block-scoped
  • Cannot be reassigned
  • Cannot be redeclared
  • Must be initialized during declaration
  • Hoisted but in the TDZ

Call, Apply, Bind in JavaScript

call() invokes the function immediately then allows our to pass arguments one by one. It explicitly set the value of this to a specific object. It is often used for function borrowing.


We have a new object userObj2. Now if we want to use the function "fullname" of the object "userObj" to this "userObj2", then we need to call it like below. This terms also called function borrowing.

How call() method works

01. first we need to call the function fullname with reference of userObj, after that we use .call() method.

02. when we add call() method, behind the scene "fullname" function already invoked, because we already wriiten a reference of "fullname" function with "userObj" object. Now inside the call() method, we can pass arguments one by one with the target object reference first.

03. If the borrowing function is independent, then we directly refer the function name and add call()

04. As per call() syntax [fullname.call(targetedObject, arg1, arg2, arg3)]. When we use extra argument, then those parameters need to passed inside that function()


apply() method is similar to call() method. The only difference is that instead of passing arguments one by one, we pass an array of arguments.


bind() method is similar to call() method. The only difference is that instead of invoking the function, it returns a new function.


Why do we need bind()?

bind() is used when you want to create a new function with a fixed this value, but do not want to execute the function immediately. Means when we bind the function, we don't want to invoke it. It returns a new function with fixed this value. Because it is returning a new function so, without calling the new function, we can't invoke the bind function. Sometimes a function loses its original this context when it's passed around because that function is called as a standalone function, so this is no longer person.


Event Delegation

Event Delegation is a technique where we attach a single event listener to a parent element instead of attaching event listeners to multiple child elements. It works because of event bubbling. It improves performance, reduces memory usage, and automatically supports dynamically added elements.
