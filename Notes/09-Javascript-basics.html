JavaScript Basic



Data Types in JavaScript:
Primitive Data Types :
  1. string : "Hello World"
  2. number : 1234
  3. boolean : true/false
  4. undefined : Not defined / absence of value
  5. null : empty
  6. bigInt : 12345678901234567890123456789n
  7. symbol : Symbol("unique")

Non-premitive Data Types :
  1. object :
    • object : { name: "Jhon", age: 30 }
    • array : [1, 2, 3]
    • function : function(){}

Different between == and ===

== : Equal to value

=== : Strict equal to value and type


Different between undefined and null

null : empty

undefined : Represent a variable that has been declared but not assigned value
