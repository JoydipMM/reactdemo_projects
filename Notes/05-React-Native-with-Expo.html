Create React Native App with Expo

If we create app inside a exiting folder then, open a terminal inside of that folder and run command.

command: npx create-expo-app@latest --template default@sdk-54 ./

Note: For this sdk-54 required node version 20


Or we can run below command to create fresh app

Command: npx create-expo-app@latest app-name


Run Application with Expo

Command: npx expo start


Remove defalt demo design

Command: npm run reset-project [remove demo files]

Do you want to move existing files to /app-example instead of deleting them? (Y/n): n

After remove done, run again npx expo start
