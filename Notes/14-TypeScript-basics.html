TypeScript Installation and Setup

First install node.js

Then install npm install -g typescript / npm install typescript --save-dev

Create app.ts file

Run this command: npx tsc app.ts to convert ts to js. because browser can't read ts file

After run the above command it will create a app.js file, where we can see the actual js code

Run this command: npx tsc app.ts --watch this will automatically convert ts to js. NO need to manually run npx tsc app.ts

Interface in TypeScript

Interface is a contract that defines the structure of an object. It is a type that can be used to describe the shape of an object.

We can not use union (|) or intersection (&) with interface

Combine Interface in TypeScript
Intersection Types in TypeScript

An Intersection Type (&) in TypeScript combines multiple types into a single type. The resulting type must satisfy all of the combined types.

Think of it as:

  • Union (|) = OR → A value can be one type or another.
  • Intersection (&) = AND → A value must have everything from all types.

Enum Data Type in TypeScript

In TypeScript, an enum (short for enumeration) is a special data type that lets you define a set of named constant values. It makes your code more readable and reduces the chance of using invalid values.

Benefits:

  • Type safety
  • Autocomplete
  • Readable code
  • Easier maintenance

Numeric Enum (Default):

By default, TypeScript assigns numbers starting from 0.

Custom Numeric Enum and String Enum:

You can specify where numbering starts. Also instead of numbers, each value can be a string.
