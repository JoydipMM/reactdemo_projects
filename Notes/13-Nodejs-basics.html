Node Module system

Node Module system allows us to organise our code in multiple pieces of code. Means node js has a module system where we will be able to create different modules and then we use those modules in a single root module. Suppose we have three modules module01.js, module02.js and module03.js. So now we can use those modules in a single root module index.js and at the end the root file(index.js) will be rendered. In node.js each file is treated as a separate module.


How we use node module system

  • module.exports to export a module -> similar to export
  • require() function to import a module -> similar to import
Important Note:

Node.js commonly use CommonJS module system. In this module system module.exports is used to export a module. And require() is used to import a module

Example of Node Module system

Suppose we have index.js, and calculate.js file. In calcualate.js file we have functions sum and minus and we export them using module.exports and in index.js file we import those functions using require()

Path Module

The Path module is a built-in Node.js module that helps you work with file and directory paths. It provides utilities to create, manipulate, normalize, and resolve file paths in a way that works across different operating systems. Since it's a built-in module, you don't need to install it.


Importing the Path Module

in CommonJS we use const path = require("path");

in ES Module we use import path from "path";


Use of Path Module


path.resolve()

path.resolve() is a method of Node.js's built-in path module. It converts a sequence of path segments into an absolute path.

Syntax

  • Accepts zero or more path segments.
  • Processes the paths from right to left.
  • Stops when it encounters an absolute path.
  • If no absolute path is found, it uses the current working directory (process.cwd()).

Importing the Path Module


When should you use path.resolve()?

Use path.resolve() when you need an absolute path, such as when:

  • Reading or writing files with the fs module.
  • Configuring file uploads.
  • Serving static assets in web servers.
  • Building reliable paths that don't depend on where a script is called from.

Summary

  • path.resolve() always returns an absolute path.
  • It resolves . (current directory) and .. (parent directory).
  • It processes path segments from right to left and stops when it finds an absolute path.
  • If no absolute path is provided, it starts from the current working directory (process.cwd()).

Use path.normalize() when you:

  • Remove redundant separators (// or \\).
