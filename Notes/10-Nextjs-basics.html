Next.js Basic

We use Next.js because React is only a UI library, while Next.js is a full-stack framework built on top of React. It provides server-side rendering, static generation, server components, API routes, built-in routing, caching, image optimization, and many performance features out of the box.

These features help improve SEO, reduce client-side JavaScript, speed up page loads, and simplify application architecture. In production applications such as e-commerce platforms, SaaS products, OTT platforms, and content websites, Next.js allows us to build scalable, high-performance applications with a better developer experience than plain React.

It extends React by adding features such as:

  • Server-side rendering : SSR
  • Static site generation : SSG
  • Incremental Static Regeneration : ISR
  • Static export : SSR
  • Server Component
  • Server Actions
  • Built-in Routing
  • API routes
  • caching
  • Full-Stack Capabilities
  • Performance Optimizations: Image optimization, Streaming, Lazy Loading, Route-level caching, Partial Prerendering

What is Routing?

Routing is the mechanism that maps a URL to a specific page, component, or resource in an application. When a user visits a URL, the routing system determines which page should be rendered.


How Routing Works in Next.js

Next.js uses File-Based Routing. Next.js automatically creates routes from folders and files inside the app directory.


Types of Routing in Next.js
  1. Static Routing
  2. Dynamic Routing
  3. Nested Routing
  4. Catch-All Routes
  5. Optional Cache-All Routes
  6. Route Groups
  7. Parallel Routes
  8. Intercepting Routes

1. Static Routing

This type of routing is called Fixed routes. In this type of routing, the URL is fixed and URL will be the same as the folder name.


2. Dynamic Routing

Routes with dynamic parameters.


3. Nested Routing

Folders create nested URLs.


4. Catch-All Routes

Handle multiple URL segments.
Example: localhost:3000/products/electronics/smartphones/redmi-8. Here products, electronics, smartphones and redmi-8 all are called Segments of URL.


Important Note:

If we don't have any segments then it will show 404 page

Example: If the URL is http://localhost:3000/docs then it will show 404 page

Example URL: http://localhost:3000/docs: Show the 404 page


Or if we have a page.jsx/tsx inside docs folder then it will show the Doc page

Example URL: http://localhost:3000/docs: Show the Docs page


Solution

1. We can create page.tsx inside docs folder to avoid this issue

2. We can use Optional Catch-All Route to fixed this issue

5. Optional Catch-All Route

We use Double Square Bracket to create Optional Catch-All Route like [[...slug]]


6. Route Groups

Organize routes without affecting URLs. The convention of route group is (foldername). This type of route help us to organize routes.


7. Parallel Routes

Render multiple route segments simultaneously.
