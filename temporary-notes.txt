Next.js <Form /> Component
------------------------------------------------
The <Form /> component in Next.js is an enhanced version of the HTML <form> element that integrates tightly with the App Router, Server Actions, and client navigation.

Instead of manually handling form submission with JavaScript, Next.js lets you directly connect a form to server functions or routes.

Why Next.js introduced <Form/>
------------------------------------------------
In traditional React or Next.js apps, forms required:
onSubmit handlers
fetch() calls
API routes
manual navigation

Example: 
const handleSubmit = async (e) => {
e.preventDefault();
await fetch("/api/data", {method:"POST", ....})
} 

Now with Next.js App Router:
Form directly calls server actions
No API route required
Less boilerplate code

How <Form/> works
------------------------------------------------
The behavior of <Form> depends on the type of action prop

1. When action is a string: <Form action="/search" >...</Form>
then it's behavior:
a. work like normal HTML form
b. Uses GET request
c. Converts from inputs to URL search params
d. Performs "client-side navigation"

Converts from inputs to URL search params > when user submit the form then form data convert to url params like: /search?title=raja&age=40

2. When action is a function (Server Action) <Form action={createPostAction} >...</Form>
then it's behavior: 
a. Calls a Server Action
b. Sends data via POST
c. No API router required
d. Function receives "FormData" automatically. example: async function createPostAction(){...}

Benefits of using <Form/>
------------------------------------------------

1. Less Boilerplate
No need for:
a. API routes
b. Fetch requests
c. manual event handling

2. Direct Server Communication
Forms can call "Server Actions" directly, reducing architecture complexity.

3. Client-Side Navigation
No full reload
benefits:
a. faster User experience
b. preserved state
c. layouts stay mounted

4. URL Search Param Integration
great for:
a. search bars
b. filters
c. pagination

What is Metadata?
-------------------------
Metadata is a data that describes a webpage.
It usually lives inside the HTML <head> section and provides information about 
the page to browsers, search engines and social media platforms.

Examples of Metadata:
page title
Description
OpenGraph tags (for social media sharing)
Twitter cards
Robots instructions
Icons / Favicons

Why should we care about Metadata?  
-------------------------
metadata is important because it affects SEO, sharing and user trust.

1. Search Engine Optimization (SEO)
-------------------------
Search engines like Google use metadata to understand your page.

2. Social Media Sharing
-------------------------
When someone shares a link on twitter, linkedin, metadata controls the preview.
Example preview:

3. Browser Experience
-------------------------
metadata also controls:
a. page title in browser tabs
b. favicons
c. viewport behavior
Next.js automatically includes basic meta tags like charset and viewport even if you don't define them.


Metadata in Next.js
-----------------------------------------------
Next.js provides a "metadata API" that automatically generates <head> tags for your pages.
you define metadata inside:
layout / page

export const metadata = {
title: "My Website",
description: "My website description"
}

In webpage next.js automatically generates code like below:
<head>
....
<title>My Website</title>
<meta name="description" content="My website description" >
</head>


Static vs Dynamic Metadata
--------------------------
Next.js supports two types of metadata:
1. Static Metadata
Static metadata is fixed metadata that does not change.
It is generated at build time.
>> best for pages like:
a. Home
b. About
c. Contact
d. Pricing
In next.js we found static metadata in root layout.tsx

2. Dynamic Metadata
Dynamic metadata changes based on:
a. route parameters
b. API data
c. database content
It is created using "generateMetadata()" method

Static Open Graph Image
------------------------------------------

what is an Open Graph Image?
----------------
An Open Graph (OG) image is the preview image that appears when someone shares your website link on social media platforms.

What is a Static Open Graph Image?
-------------------
A static Open Graph Image is a fixed image file used as a preview image for a page.
In Next.js, you can add it by placing an image file named: opengraph-image.png  / opengraph-image.jpg [1200 x 630 ]

Why Static OG Images matter:
-------------------------
1. Better Social Media Preview
2. Stronger Branding
3. Better SEO and Shareability


How static OG image use in Next.js
----------------------------------
1. We place the image inside "app" folder and change the to "opengraph-image.png  / opengraph-image.jpg"
2. <meta name="twitter:image" content="http://localhost:3000/opengraph-image.jpg?opengraph-image.1hv-k0j8_s5wh.jpg">
