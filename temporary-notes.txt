Next.js <Form /> Component
------------------------------------------------
The <Form /> component in Next.js is an enhanced version of the HTML <form> element that integrates tightly with the App Router, Server Actions, and client navigation.

Instead of manually handling form submission with JavaScript, Next.js lets you directly connect a form to server functions or routes.

Why Next.js introduced <Form/>
------------------------------------------------
In traditional React or Next.js apps, forms required:
onSubmit handlers
fetch() calls
API routes
manual navigation

Example: 
const handleSubmit = async (e) => {
e.preventDefault();
await fetch("/api/data", {method:"POST", ....})
} 

Now with Next.js App Router:
Form directly calls server actions
No API route required
Less boilerplate code

How <Form/> works
------------------------------------------------
The behavior of <Form> depends on the type of action prop

1. When action is a string: <Form action="/search" >...</Form>
then it's behavior:
a. work like normal HTML form
b. Uses GET request
c. Converts from inputs to URL search params
d. Performs "client-side navigation"

Converts from inputs to URL search params > when user submit the form then form data convert to url params like: /search?title=raja&age=40

2. When action is a function (Server Action) <Form action={createPostAction} >...</Form>
then it's behavior: 
a. Calls a Server Action
b. Sends data via POST
c. No API router required
d. Function receives "FormData" automatically. example: async function createPostAction(){...}

Benefits of using <Form/>
------------------------------------------------

1. Less Boilerplate
No need for:
a. API routes
b. Fetch requests
c. manual event handling

2. Direct Server Communication
Forms can call "Server Actions" directly, reducing architecture complexity.

3. Client-Side Navigation
No full reload
benefits:
a. faster User experience
b. preserved state
c. layouts stay mounted

4. URL Search Param Integration
great for:
a. search bars
b. filters
c. pagination
