Create Redux Store

install react-redux and @reduxjs/toolkit

Install Command npm i react-redux @reduxjs/toolkit

Below steps are to create and use redux store

  1. Configure Store and export it
  2. Create Slice and export default the slice reducer and name export of the reducers
  3. Wrap full app with Provider
  4. Use useDispatch for dispatch action to reducer to store the data
  5. Use useSelector for get the data from store
