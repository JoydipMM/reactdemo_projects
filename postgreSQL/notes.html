Check PostgreSQL is sucessfully installed and running

open Command Prompt [ if Command Prompt already open then close it first ] and run the following command:

psql -U postgres

You should see something like: Password for user postgres:

Enter password what we set when we installed PostgreSQL

After entering the password: postgres=# this will show us which means that PostgreSQL is successfully installed and running

Constraint

In PostgreSQL, a constraint is a rule applied to a table column (or table) to control what data is allowed.

Main Types of Constraints:


SERIAL PRIMARY KEY

SERIAL PRIMARY KEY is not technically required for every table in PostgreSQL, but in most production applications, every table should have some form of primary key because it uniquely identifies each row.

Why Tables Need a Primary Key

With primary keys we uniquely identify one specific row Update, Delete, Reference, Relate data
