Constraint

In PostgreSQL, a constraint is a rule applied to a table column (or table) to control what data is allowed.

Main Types of Constraints:


SERIAL PRIMARY KEY

SERIAL PRIMARY KEY is not technically required for every table in PostgreSQL, but in most production applications, every table should have some form of primary key because it uniquely identifies each row.

Why Tables Need a Primary Key

With primary keys we uniquely identify one specific row Update, Delete, Reference, Relate data


More Query Filters

  • LIKE: The LIKE operator is used in a WHERE clause to search for a specified pattern in a column
  • ILIKE : The ILIKE operator is used in a WHERE clause to search for a specified pattern in a column
  • % : The % operator is used to match any number of characters
  • IN: The IN operator is used to test whether a value matches any value in a list of values
  • NOT IN: The NOT IN operator is used to test whether a value does not match any value in a list of values
  • BETWEEN: The BETWEEN operator is used to search for a value between two values
